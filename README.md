## 🧠 Problem-Solving Approach

For each problem, my goal is to follow a structured approach:

```text
1. Understand the problem
        ↓
2. Identify the input and output
        ↓
3. Think about a brute-force solution
        ↓
4. Identify possible optimizations
        ↓
5. Select the appropriate DSA pattern
        ↓
6. Implement the solution in Java
        ↓
7. Test with examples
        ↓
8. Analyze Time Complexity
        ↓
9. Analyze Space Complexity
```

---

## ⏱️ Complexity Analysis

I focus not only on getting the correct answer but also on understanding the efficiency of the solution.

For example:

### Brute Force

```text
Time Complexity: O(n²)
Space Complexity: O(1)
```

### Optimized Approach

```text
Time Complexity: O(n)
Space Complexity: O(n)
```

The goal is to understand **why** an optimized solution performs better rather than simply memorizing code.
